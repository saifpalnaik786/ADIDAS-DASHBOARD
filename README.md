# ADIDAS-DASHBOARD

Adidas Sales Analytics Dashboard (Excel)
Project Overview

Built an interactive Excel dashboard to analyze Adidas sales data for 2020–2021 across regions, retailers, products, and sales channels.

Tools Used

Microsoft Excel

Pivot Tables

Pivot Charts

Slicers

Data Cleaning

Key Analysis Areas

Sales by Region

Units Sold by Product

Profit by Sales Channel

Retailer-wise Sales

Monthly Sales Trends

Key Insights

West region generated highest sales (27M).

Midwest recorded lowest performance.

Certain retailers contributed majority revenue.

Profitability varied significantly across sales methods.

Business Recommendations

Reallocate inventory to high-performing regions.

Optimize pricing strategies in outlet channels.

Strengthen partnerships with top-performing retailers.
